Explaining Common Programming Variables and Terms

💡 What are they?

In programming, we use short, meaningful variable names to make our code easier to read and write. These are not special keywords; they are just common conventions that programmers follow worldwide.

🔢 Loop Counters & Indices

  • i: Stands for **"index"**. Think of it as your primary finger when you count items in a list. It tracks your position in the main loop.
  • j: Used when you have a loop *inside* another loop (a "nested loop"). While your `i` finger stays on a main task, your `j` finger can iterate through the sub-tasks.
  • k: Used for triple-nested loops or as a third counter. Less common but follows the same pattern.

🎯 Pointer Variables (Very Important in DSA)

  • left & right: Used in two-pointer techniques. Like having one finger at the start of a book and another at the end, moving them toward each other.
  • start & end: Similar to left/right, but often used for array slicing or defining ranges.
  • head & tail: Common in linked lists. `head` points to the first element, `tail` to the last.
  • prev & next: Short for "previous" and "next". Used when traversing data structures like linked lists.
  • mid or middle: The middle point, especially in binary search algorithms.

📊 Data Holder Variables

  • temp: Short for "temporary". Used to temporarily store a value during swapping or calculations.
  • result: Stores the final answer or output of a function.
  • count: Keeps track of how many times something occurs.
  • sum: Accumulates the total of numbers being added.
  • max_val & min_val: Store maximum and minimum values found so far.
  • target: The value we're searching for in search algorithms.

🏗️ Data Structure Variables

  • arr or array: Short for "array" - a collection of elements.
  • lst or list: Python's list data structure.
  • stack & queue: Specific data structure variables following LIFO and FIFO principles.
  • node: An element in linked lists or trees.
  • key & value: Used with dictionaries/hash maps. Key is the identifier, value is the data.

✨ Pro Tips for Beginners

  • Use descriptive names: `for student_name in students:` is much clearer than `for i in range(len(students)):`
  • Stay consistent: If you use `left` and `right` in one function, don't switch to `start` and `end` in similar functions
  • Common is good: Using these conventional names helps other programmers (and your future self) understand your code quickly
  • Context matters: `i` is fine for simple loops, but `student_index` might be better in complex educational software

🔹 Array & String Basics

1. Find the largest/smallest element in an array

💡 Real-Life Analogy

Finding the tallest person in a line. You assume the first person is the tallest, then you compare every other person to them, updating your choice if you find someone taller.

🐍 Python Code

def find_largest(arr):
    if not arr: return None # Handle empty array
    largest = arr[0]
    for num in arr:
        if num > largest:
            largest = num
    return largest
print(find_largest([10, 5, 20, 8, 15])) # Output: 20

📖 Explanation

  • Edge Case Handling: `if not arr: return None` checks if the array is empty. This prevents crashes when someone passes an empty list.
  • Initialization: We assume the first element (`arr[0]`) is the largest as a starting point. This gives us something to compare against.
  • The Loop: `for num in arr:` goes through each number. This is called "iterating over" the array. Python automatically gives us each element one by one.
  • The Comparison: `if num > largest:` asks "Is this number bigger than what I currently think is the biggest?"
  • The Update: When we find a bigger number, `largest = num` updates our "current champion."
  • Why This Works: By the end, we've compared every number, so `largest` must contain the actual largest value.

⚡ Time & Space Complexity

  • Time: O(n) - We look at each element exactly once
  • Space: O(1) - We only use one extra variable regardless of input size

❌ Common Beginner Mistakes

  • Forgetting to handle empty arrays (causes crashes)
  • Starting `largest` at 0 instead of `arr[0]` (fails with negative numbers)
  • Using `>=` instead of `>` (works, but unnecessary comparisons)

2. Reverse an array (or string)

💡 Real-Life Analogy

Swapping books on a shelf. You swap the first book with the last, the second with the second-to-last, and so on, until you meet in the middle.

🐍 Python Code

def reverse_array(arr):
    left, right = 0, len(arr) - 1
    while left < right:
        arr[left], arr[right] = arr[right], arr[left] # Swap
        left += 1
        right -= 1
    return arr
print(reverse_array([1, 2, 3, 4, 5])) # Output: [5, 4, 3, 2, 1]

📖 Explanation

  • Two Pointers Technique: We use two "pointers" (indices), `left` starting at position 0 (beginning) and `right` at position `len(arr) - 1` (end).
  • The Strategy: Instead of creating a new array, we swap elements in-place, which saves memory.
  • Loop Condition: `while left < right` ensures we only swap until the pointers meet in the middle. If they cross, we're done!
  • The Swap Magic: `arr[left], arr[right] = arr[right], arr[left]` is Python's elegant way to swap two values without needing a temporary variable.
  • Moving Inward: `left += 1` and `right -= 1` move our pointers toward each other, processing the next pair to swap.
  • Visual Example: [1,2,3,4,5] → swap 1&5 → [5,2,3,4,1] → swap 2&4 → [5,4,3,2,1]. The middle element (3) never moves!

⚡ Time & Space Complexity

  • Time: O(n/2) = O(n) - We swap roughly half the elements
  • Space: O(1) - We modify in-place, no extra array needed

❌ Common Beginner Mistakes

  • Using `<=` instead of `<` in the condition (causes middle element to swap with itself)
  • Creating a new array instead of in-place modification (wastes memory)
  • Forgetting to move both pointers (infinite loop!)

3. Check if a string is a palindrome

💡 Real-Life Analogy

A word that reads the same forwards and backward, like "level" or "racecar". You check by comparing the first and last letters, then the second and second-to-last, etc.

🐍 Python Code

def is_palindrome(s):
    left, right = 0, len(s) - 1
    while left < right:
        if s[left] != s[right]:
            return False # Mismatch found
        left += 1
        right -= 1
    return True # All characters matched
print(is_palindrome("racecar")) # Output: True

📖 Explanation

  • Two Pointers Again: Like reversing an array, we use `left` and `right` pointers starting at the string's ends.
  • The Comparison Logic: `if s[left] != s[right]:` compares characters at mirror positions. If any pair doesn't match, it's definitely not a palindrome.
  • Early Exit: `return False` immediately stops the function when we find a mismatch - no need to check further!
  • Success Case: If we get through all comparisons without finding mismatches, `return True` confirms it's a palindrome.
  • Why This Works: A palindrome must be identical when read forwards and backwards, so every character at position `i` must match the character at position `n-1-i`.
  • Example Walkthrough: "racecar" → compare r&r ✓, a&a ✓, c&c ✓ → palindrome!

⚡ Time & Space Complexity

  • Time: O(n/2) = O(n) - We check at most half the string
  • Space: O(1) - Only using two pointer variables

❌ Common Beginner Mistakes

  • Not handling case sensitivity ("Racecar" vs "racecar")
  • Not ignoring spaces and punctuation in real-world scenarios
  • Reversing the entire string first (works but wastes time and space)

4. Find the second largest element in an array

💡 Real-Life Analogy

Finding the winner and the runner-up in a race. You need to keep track of the two fastest times you've seen so far.

🐍 Python Code

import float
def find_second_largest(arr):
    if len(arr) < 2: return None
    largest = -float('inf')
    second_largest = -float('inf')
    for num in arr:
        if num > largest:
            second_largest = largest
            largest = num
        elif num > second_largest and num != largest:
            second_largest = num
    return second_largest if second_largest != -float('inf') else None
print(find_second_largest([10, 5, 20, 8, 15])) # Output: 15

📖 Explanation

  • Why float('inf')? `float('inf')` represents mathematical infinity in Python. We use `-float('inf')` (negative infinity) so ANY real number will be larger than our starting values.
  • Edge Case: `if len(arr) < 2: return None` - You need at least 2 elements to have a "second largest"!
  • Initialization Strategy: Starting with negative infinity ensures our algorithm works even with arrays full of negative numbers.
  • Case 1 - New Champion: When `num > largest`, the old champion becomes the runner-up, and we have a new champion.
  • Case 2 - New Runner-up: When a number isn't the largest but beats our current second_largest AND isn't equal to largest (avoids duplicates), it becomes our new runner-up.
  • Final Check: We return `None` if `second_largest` is still negative infinity, meaning we never found a valid second largest (e.g., all elements are identical).
  • Example Walkthrough: [10, 5, 20, 8, 15] → largest=10, second=−∞ → largest=20, second=10 → second stays 10 → second stays 10 → largest=20, second=15

⚡ Time & Space Complexity

  • Time: O(n) - Single pass through the array
  • Space: O(1) - Only two extra variables

❌ Common Beginner Mistakes

  • Not handling duplicate largest values correctly
  • Starting with 0 instead of negative infinity (fails with negative arrays)
  • Sorting the array first (works but takes O(n log n) time unnecessarily)
  • Not checking `num != largest` (could make duplicates the second largest)

5. Count the frequency of elements in an array

💡 Real-Life Analogy

Tallying votes in an election. You have a list of candidate names (the array) and you create a summary sheet (a dictionary) to count how many votes each candidate received.

🐍 Python Code

def count_frequency(arr):
    frequency = {} # Create an empty dictionary
    for item in arr:
        frequency[item] = frequency.get(item, 0) + 1
    return frequency
print(count_frequency(['apple', 'banana', 'apple', 'orange'])) 
# Output: {'apple': 2, 'banana': 1, 'orange': 1}

📖 Explanation

  • Dictionary as Counter: A dictionary in Python is perfect for counting because keys are unique and we can store counts as values.
  • The get() Method Magic: `frequency.get(item, 0)` asks "What's the current count for this item?" If the item doesn't exist yet, it returns 0 instead of crashing.
  • The Counting Logic: `frequency.get(item, 0) + 1` takes the current count (or 0 if new) and adds 1 to it.
  • Memory Efficient: Instead of checking "does this key exist?" separately, `.get()` handles both checking and defaulting in one step.
  • Alternative Approach: You could also use `collections.Counter(arr)` for the same result, but understanding the manual approach teaches you how dictionaries work.
  • Real-World Usage: This pattern appears everywhere - counting website visits, analyzing survey responses, finding most common words in text, etc.

⚡ Time & Space Complexity

  • Time: O(n) - We visit each element exactly once
  • Space: O(k) where k is the number of unique elements

❌ Common Beginner Mistakes

  • Using `frequency[item] += 1` without checking if key exists first (KeyError!)
  • Manually checking `if item in frequency:` before incrementing (works but verbose)
  • Not understanding that dictionary keys must be immutable (strings, numbers OK; lists not OK)

6. Rotate an array by k positions

💡 Real-Life Analogy

Shifting people in a circular line. If you need to move the line forward by 2 positions, the last 2 people go to the front.

🐍 Python Code

def rotate_array(arr, k):
    n = len(arr)
    k = k % n # Handle cases where k > n
    # Slice the array at n-k and concatenate the two parts
    return arr[-k:] + arr[:-k]
print(rotate_array([1, 2, 3, 4, 5], 2)) # Output: [4, 5, 1, 2, 3]

📖 Explanation

  • Modulus: `k = k % n` ensures that if `k` is larger than the array length, we only consider the effective rotation.
  • Slicing: Python's slicing makes this easy. `arr[-k:]` gets the last `k` elements. `arr[:-k]` gets all elements *except* the last `k`.
  • Concatenation: We combine these two slices with `+` to form the new, rotated array.

7. Find the missing number in an array of size n containing numbers 1..n+1

💡 Real-Life Analogy

You have a set of numbered puzzle pieces from 1 to 10, but you only count 9 pieces. To find the missing one, you calculate the sum of numbers from 1 to 10 and subtract the sum of the pieces you have.

🐍 Python Code

def find_missing_number(arr):
    n = len(arr) + 1
    expected_sum = n * (n + 1) // 2
    actual_sum = sum(arr)
    return expected_sum - actual_sum
print(find_missing_number([1, 2, 4, 5, 6])) # n=6, missing 3. Output: 3

📖 Explanation

  • Expected Sum: We use the mathematical formula `n * (n + 1) / 2` to calculate what the sum *should* be if no number were missing.
  • Actual Sum: We use Python's built-in `sum()` function to get the sum of the elements we actually have.
  • Difference: The difference between the expected and actual sum is the missing number.

8. Merge two sorted arrays

💡 Real-Life Analogy

Merging two sorted lines of people by height. You look at the first person in each line, pick the shorter one to go next in the new line, and repeat the process.

🐍 Python Code

def merge_sorted_arrays(arr1, arr2):
    merged = []
    i, j = 0, 0
    while i < len(arr1) and j < len(arr2):
        if arr1[i] < arr2[j]:
            merged.append(arr1[i])
            i += 1
        else:
            merged.append(arr2[j])
            j += 1
    merged.extend(arr1[i:]) # Add leftovers from arr1
    merged.extend(arr2[j:]) # Add leftovers from arr2
    return merged
print(merge_sorted_arrays([1, 3, 5], [2, 4, 6])) # Output: [1, 2, 3, 4, 5, 6]

📖 Explanation

  • Pointers `i` and `j`: `i` tracks the position in `arr1`, and `j` tracks the position in `arr2`.
  • Main Loop: The `while` loop compares elements from both arrays and appends the smaller one to the `merged` list, advancing the corresponding pointer.
  • Cleanup: After the loop, one array will be exhausted while the other may still have elements. The `extend` lines add all remaining elements.

🔹 Searching & Sorting

9. Implement linear search

💡 Real-Life Analogy

Looking for your car in a large parking lot row. You start at one end and check every single car, one by one, until you find yours.

🐍 Python Code

def linear_search(arr, target):
    # Loop through each index position in the array
    for i in range(len(arr)):
        # Check if current element matches what we're looking for
        if arr[i] == target:
            return i # Found it! Return the index position
    return -1 # Not found - return -1 as a "not found" signal

# Example usage:
print(linear_search([5, 2, 8, 12, 3], 8))  # Output: 2 (8 is at index 2)
print(linear_search([5, 2, 8, 12, 3], 99)) # Output: -1 (99 not found)

📖 Explanation

  • Iteration with `i`: The `for` loop goes through each index `i` of the array, from `0` to the end.
  • Comparison: `if arr[i] == target:` checks if the element at the current index `i` is the one we're looking for.
  • Return: If found, we return the index `i` immediately. If the loop finishes without finding the target, we return `-1`.

10. Implement binary search

💡 Real-Life Analogy

Searching for a word in a physical dictionary. You don't start from the first page. You open to the middle, see if your word comes before or after that page, and then discard half the dictionary. You repeat this process.

🐍 Python Code

def binary_search(sorted_arr, target):
    left, right = 0, len(sorted_arr) - 1
    while left <= right:
        mid = (left + right) // 2
        if sorted_arr[mid] == target:
            return mid
        elif sorted_arr[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    return -1
print(binary_search([2, 5, 7, 8, 11, 12], 11)) # Output: 4

📖 Explanation

  • CRITICAL Pre-requisite: Binary search ONLY works on **sorted** arrays. If your array isn't sorted, you'll get wrong results!
  • The Search Space: We define our search area using `left` and `right` pointers. Initially, we search the entire array.
  • Finding the Middle: `mid = (left + right) // 2` finds the middle index. The `//` is integer division (no decimals).
  • Three-Way Decision: At each step, we compare `sorted_arr[mid]` with our `target` and make one of three decisions:
  • Found it! If `sorted_arr[mid] == target`, return the index immediately.
  • Go right: If `sorted_arr[mid] < target`, our target must be in the right half, so `left = mid + 1`.
  • Go left: If `sorted_arr[mid] > target`, our target must be in the left half, so `right = mid - 1`.
  • Why It's Fast: Each step eliminates half the remaining elements, making it much faster than linear search for large arrays.
  • Loop Termination: `while left <= right` continues until our search space becomes invalid (when left pointer crosses right pointer).

⚡ Time & Space Complexity

  • Time: O(log n) - We cut the search space in half each time
  • Space: O(1) - Only using a few pointer variables

❌ Common Beginner Mistakes

  • Forgetting that the array must be sorted first
  • Using `while left < right` instead of `while left <= right` (misses some cases)
  • Integer overflow: `mid = (left + right) // 2` can overflow in some languages (Python handles this automatically)
  • Off-by-one errors: using `mid` instead of `mid + 1` or `mid - 1` when updating pointers

11. Sort an array using bubble sort

💡 Real-Life Analogy

Imagine bubbles in a tank of water. The largest bubbles rise to the top first. In each "pass" through the array, the largest unsorted element "bubbles up" to its correct position at the end.

🐍 Python Code

def bubble_sort(arr):
    n = len(arr)
    # Outer loop: controls how many passes we make
    for i in range(n):
        # Inner loop: compares adjacent elements
        # We reduce the range each time because the largest elements "bubble up" to the end
        for j in range(0, n - i - 1):
            # If current element is greater than the next one, swap them
            if arr[j] > arr[j + 1]:
                arr[j], arr[j + 1] = arr[j + 1], arr[j] # Python swap
    return arr

# Example: Watch the largest elements "bubble" to the end
print(bubble_sort([64, 34, 25, 12, 22, 11, 90])) 
# Output: [11, 12, 22, 25, 34, 64, 90]

📖 Explanation

  • Outer Loop (`i`): This loop controls the number of passes. After `i` passes, the last `i` elements are guaranteed to be sorted.
  • Inner Loop (`j`): This loop iterates through the unsorted part of the array, comparing adjacent elements.
  • Swap: If an element is greater than the one next to it, they are swapped. This action is what moves the largest elements towards the end.

12. Find the first non-repeating character in a string

💡 Real-Life Analogy

Taking attendance. You go through the list of names, making a tally mark for each. Then, you look at your tally sheet from the beginning to find the first name with only one mark.

🐍 Python Code

def first_non_repeating_char(s):
    counts = {}
    for char in s:
        counts[char] = counts.get(char, 0) + 1
    for char in s:
        if counts[char] == 1:
            return char
    return None
print(first_non_repeating_char("loveleetcode")) # Output: 'v'

📖 Explanation

  • First Pass (Count): We loop through the string once to build a frequency map (dictionary) of all characters.
  • Second Pass (Find): We loop through the string a second time. For each character, we look up its count in our map. The first one we find with a count of `1` is our answer.

def are_anagrams(s1, s2):

📖 Explanation

🔹 Linked List (basic level)

15. Implement a singly linked list and insert a node

💡 Real-Life Analogy

A treasure hunt. Each clue is a `Node` containing some information (`data`) and the location of the next clue (`next`). The `head` is the first clue you are given.

🐍 Python Code

class Node:
    def __init__(self, data):
        self.data = data
        self.next = None

class LinkedList:
    def __init__(self):
        self.head = None
    
    def insert_at_end(self, data):
        new_node = Node(data)
        if not self.head:
            self.head = new_node
            return
        last_node = self.head
        while last_node.next:
            last_node = last_node.next
        last_node.next = new_node

📖 Explanation

  • Understanding Node: Think of a Node like a train car. Each car carries some cargo (`data`) and has a connection to the next car (`next`).
  • Understanding LinkedList: The LinkedList class is like the train conductor who knows where the train starts (`head`) but doesn't need to know about every car.
  • Why `self.next = None`? When we create a new node, it doesn't point to anything yet, so `next` starts as `None` (meaning "no next car").
  • Insertion Logic:
    • If the train is empty (`not self.head`), our new car becomes the entire train.
    • Otherwise, we walk from the head to the very last car (`while last_node.next:`).
    • We connect the last car to our new car (`last_node.next = new_node`).
  • Why Traverse to End? Unlike arrays where we can jump to any position instantly, linked lists require us to follow the chain from the beginning.

⚡ Time & Space Complexity

  • Time: O(n) for insertion at end (must traverse to find last node)
  • Space: O(1) for each insertion (just creating one new node)

❌ Common Beginner Mistakes

  • Forgetting to handle the empty list case (trying to traverse when head is None)
  • Not updating the `next` pointer properly (breaking the chain)
  • Confusing Node (individual element) with LinkedList (the entire structure)

16. Reverse a linked list

💡 Real-Life Analogy

Reversing a train on a single track. You go to each car, unhitch it from the car in front, and re-hitch it to the car that was previously behind it. You need to keep track of the previous, current, and next car at all times.

🐍 Python Code

def reverse_linked_list(head):
    prev = None
    current = head
    while current:
        next_node = current.next # Store next node
        current.next = prev     # Reverse the pointer
        prev = current          # Move prev forward
        current = next_node     # Move current forward
    return prev # The new head is the old last node

📖 Explanation

  • Pointers: We use three pointers: `prev` (starts as `None`), `current` (starts at the `head`), and `next_node`.
  • Loop: We iterate while `current` is not `None`.
  • The Reversal Logic (in order):
    1. First, we save the next node so we don't lose the rest of the list.
    2. Then, we reverse the `current` node's pointer to point to `prev`.
    3. We then move our `prev` and `current` pointers one step forward for the next iteration.
  • New Head: When the loop ends, `prev` will be pointing to the new head of the reversed list.

17. Detect a cycle in a linked list

💡 Real-Life Analogy

Two runners on a track. One runs at normal speed (slow pointer) and the other runs twice as fast (fast pointer). If the track is a circle (a cycle), the fast runner will eventually lap the slow runner and they will meet. If it's a straight path, the fast runner will simply reach the end.

🐍 Python Code

def has_cycle(head):
    slow, fast = head, head
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
        if slow == fast:
            return True # Pointers met, cycle detected
    return False # Fast pointer reached the end

📖 Explanation

  • Two Pointers: We initialize a `slow` and a `fast` pointer, both starting at the `head`.
  • Movement: In each step of the loop, `slow` moves one node forward, while `fast` moves two nodes forward.
  • Loop Condition: The loop continues as long as `fast` and `fast.next` are not `None`. If they are, it means we've reached the end of a non-cyclical list.
  • Detection: If at any point `slow` and `fast` point to the exact same node, it proves there is a cycle in the list.

🔹 Stack & Queue

18. Implement a stack using arrays

💡 Real-Life Analogy

A stack of plates. You can only add a new plate to the top (`push`) and you can only take a plate from the top (`pop`). This is a Last-In, First-Out (LIFO) structure.

🐍 Python Code

class Stack:
    def __init__(self):
        self.items = []
    def push(self, item):
        self.items.append(item)
    def pop(self):
        if not self.is_empty():
            return self.items.pop()
    def peek(self):
        if not self.is_empty():
            return self.items[-1]
    def is_empty(self):
        return len(self.items) == 0

📖 Explanation

  • Implementation: A Python list is perfect for implementing a simple stack.
  • push: `list.append()` adds an item to the end of the list, which we consider the "top" of our stack.
  • pop: `list.pop()` removes and returns the last item, perfectly matching the LIFO principle.
  • peek: Accessing `self.items[-1]` lets us see the top item without removing it.

19. Implement a queue using arrays

💡 Real-Life Analogy

A checkout line at a grocery store. The first person to get in line is the first person to be served. This is a First-In, First-Out (FIFO) structure.

🐍 Python Code

class Queue:
    def __init__(self):
        self.items = []
    def enqueue(self, item):
        self.items.append(item)
    def dequeue(self):
        if not self.is_empty():
            return self.items.pop(0) # Remove from the front
    def is_empty(self):
        return len(self.items) == 0

📖 Explanation

  • Implementation: We use a Python list.
  • enqueue: `list.append()` adds an item to the back of the line.
  • dequeue: `list.pop(0)` removes and returns the item from the front of the line (index 0). *Note: This is inefficient for long lists. For real applications, use `collections.deque`.*

20. Check for balanced parentheses

💡 Real-Life Analogy

Stacking different sized plates. When you put an opening bracket `(` on the stack, you can only remove it with a matching `)`. If you try to close with `]` while `(` is on top, it's an error.

🐍 Python Code

def are_parentheses_balanced(s):
    stack = []
    mapping = {")": "(", "}": "{", "]": "["}
    for char in s:
        if char in mapping.values():
            stack.append(char)
        elif char in mapping:
            if not stack or mapping[char] != stack.pop():
                return False
    return not stack
print(are_parentheses_balanced("()[]{}")) # Output: True

📖 Explanation

  • Stack: We use a stack to keep track of opening brackets as we see them.
  • Opening Bracket: If we see an opening bracket, we `push` it onto the stack.
  • Closing Bracket: If we see a closing bracket, we `pop` from the stack and check if it's the correct matching opener. If the stack is empty or the brackets don't match, the string is unbalanced.
  • Final Check: If the string is balanced, the stack should be empty at the end.

21. Find the factorial of a number

💡 Real-Life Analogy

The number of unique ways you can arrange a set of distinct items. For 3 books, there are `3 * 2 * 1 = 6` ways to arrange them on a shelf. This is "3 factorial" or `3!`.

🐍 Python Code

def factorial(n):
    if n < 0: return "Invalid input"
    if n == 0: return 1
    result = 1
    for i in range(1, n + 1):
        result *= i
    return result
print(factorial(5)) # Output: 120 (5*4*3*2*1)

📖 Explanation

  • Base Cases: The factorial of 0 is 1. Negative numbers don't have factorials.
  • Initialization: We start our `result` at 1.
  • Loop: We loop from 1 up to and including `n`. In each step, we multiply the `result` by the current number `i`.

22. Check if a number is prime

💡 Real-Life Analogy

A prime number of items (like 7) can only be arranged in a single row. A non-prime number (like 6) can be arranged in other rectangles (2x3). A prime is only divisible by 1 and itself.

🐍 Python Code

# We import 'math' to use math.sqrt() function
# The math module provides mathematical functions like sqrt, ceil, floor, etc.
import math
def is_prime(n):
    if n <= 1: return False
    for i in range(2, int(math.sqrt(n)) + 1):
        if n % i == 0:
            return False
    return True
print(is_prime(13)) # Output: True
print(is_prime(12)) # Output: False

📖 Explanation

  • Why Import math? The `math` module gives us access to mathematical functions. Here we use `math.sqrt(n)` to find the square root of n efficiently.
  • Base Case Logic: Numbers ≤ 1 are not prime by mathematical definition. 2 is the smallest prime number.
  • The Square Root Optimization: If n has a divisor larger than √n, it must also have a corresponding divisor smaller than √n. So we only need to check up to √n!
  • Example: For n=36, √36=6. Instead of checking divisors 1,2,3,4,5,6,7,8...36, we only check 2,3,4,5,6. We find 6 divides 36, so it's not prime.
  • The Modulo Operator: `n % i == 0` checks if n is perfectly divisible by i (no remainder).
  • Why int()? `math.sqrt()` returns a float, but `range()` needs integers, so we convert with `int()`.
  • The +1: `int(math.sqrt(n)) + 1` ensures we include the square root itself in our range if it's a perfect square.

⚡ Time & Space Complexity

  • Time: O(√n) - Much faster than checking all numbers up to n
  • Space: O(1) - Only using a few variables

❌ Common Beginner Mistakes

  • Checking all numbers up to n instead of √n (very slow for large numbers)
  • Not handling edge cases like 0, 1, and negative numbers
  • Starting the loop from 1 instead of 2 (1 divides everything)
  • Forgetting the +1 in the range (might miss perfect square divisors)

23. Find the Fibonacci number

💡 Real-Life Analogy

A simplified model for a rabbit population's growth. Each number is the sum of the two preceding ones: 0, 1, 1, 2, 3, 5, 8...

🐍 Python Code

def fibonacci(n):
    if n <= 1: return n
    a, b = 0, 1
    for _ in range(n - 1):
        a, b = b, a + b
    return b
print(fibonacci(7)) # The 7th number is 13 (0-indexed)

📖 Explanation

  • The Fibonacci Pattern: Each number is the sum of the two preceding ones: F(0)=0, F(1)=1, F(2)=0+1=1, F(3)=1+1=2, F(4)=1+2=3, F(5)=2+3=5...
  • Base Cases: F(0)=0 and F(1)=1 are defined mathematically. These are our starting points.
  • Efficient Approach: Instead of calculating F(n-1) and F(n-2) separately (which would be very slow), we build up from the bottom.
  • The Variables: `a` holds the "current" Fibonacci number, `b` holds the "next" one.
  • The Loop Logic: We repeat `n-1` times because we start with F(0) and F(1) already known.
  • The Simultaneous Update: `a, b = b, a + b` is Python magic that updates both variables at once:
    • New `a` becomes the old `b`
    • New `b` becomes the old `a + b`
  • Example Trace for F(5): Start: a=0, b=1 → a=1, b=1 → a=1, b=2 → a=2, b=3 → a=3, b=5. Result: 5

⚡ Time & Space Complexity

  • Time: O(n) - We calculate each Fibonacci number exactly once
  • Space: O(1) - Only using two variables instead of recursion call stack

❌ Common Beginner Mistakes

  • Using naive recursion (exponential time - very slow for large n)
  • Not handling the base cases n=0 and n=1 correctly
  • Getting confused by the simultaneous assignment syntax
  • Off-by-one errors in the loop count

24. Find the GCD of two numbers

💡 Real-Life Analogy

Finding the largest possible square tile size that can perfectly cover a rectangular floor (e.g., 24x18) without any cutting. The tile size would be the GCD of the floor's dimensions.

🐍 Python Code

# Using the Euclidean Algorithm
def gcd(a, b):
    while b:
        a, b = b, a % b
    return a
print(gcd(48, 18)) # Output: 6

📖 Explanation

  • Euclidean Algorithm: This is a highly efficient classical algorithm for finding the Greatest Common Divisor (GCD).
  • Loop: The `while b:` loop continues as long as `b` is not zero.
  • The Swap: In each step, `a` becomes `b`, and `b` becomes the remainder of `a` divided by `b` (`a % b`).
  • Result: When `b` becomes `0`, the value left in `a` is the GCD.
